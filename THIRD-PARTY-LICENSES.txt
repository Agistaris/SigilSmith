Open-source components in SigilSmith (Linux x86_64)
===================================================

SigilSmith includes the open-source components listed below. Each is provided
under its own license. They are grouped by license: for each license, the
components and their copyright notices come first, then the license text,
once.

What is covered

  - 475 Rust crates compiled into the program, from its Cargo.lock (normal
    dependencies for x86_64-unknown-linux-gnu). This errs on the side of
    completeness: 69 of them only generate code while the program is built
    (procedural macros and what they use).
  - C and assembly code that some of those crates compile into the program;
    see "C and assembly code" at the end.
  - The Rust standard library from Rust 1.95.0, which is part of every Rust
    program.

Choice of license

  Where a component may be used under more than one license (for example "MIT
  OR Apache-2.0"), SigilSmith uses it under the MIT license whenever MIT is
  one of the choices, and otherwise under the first of these that is offered:
  BSD-3-Clause, BSD-2-Clause, ISC, Zlib, CC0-1.0, MIT-0, 0BSD, Unlicense,
  Apache-2.0, Apache-2.0 WITH LLVM-exception, BSL-1.0, Unicode-3.0,
  Unicode-DFS-2016, CDLA-Permissive-2.0, MPL-2.0,
  LicenseRef-Slint-Royalty-free-2.0. The licenses a component offers are shown
  in brackets when they differ from the one used.

Source code

  Components under the Mozilla Public License 2.0 are listed with the address
  where their source code is available.
